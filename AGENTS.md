# Инструкции для работы с расширением

Проект представляет собой расширение Chrome Manifest V3 для одной Scrum-доски Jira. Исходники находятся в `jira-sprint-load/`. Браузер загружает их напрямую. Руководство пользователя находится в [README.md](README.md).

## Карта кода

- `manifest.json` и `service-worker.js` открывают боковую панель по иконке расширения.
- `panel.mjs` выбирает спринт, обновляет данные и управляет локальным кешем. `panel.html`, `panel.css` и `view.mjs` отвечают за интерфейс.
- `jira.mjs` обнаруживает доски и спринты, читает задачи Jira Cloud и Data Center и замечает сохранения во вкладке Jira.
- `model.mjs` нормализует задачи и рассчитывает загрузку и ёмкость. `settings.mjs` управляет настройками доски и команды, а `team-file.mjs` задаёт формат импорта и экспорта команды.

## Правила, важные для изменений

- Читайте данные из настроенной Jira через текущую сессию пользователя. Изменения задач выполняются в Jira. Настройки и кеш хранятся в `chrome.storage.local`.
- Берите даты из выбранного спринта Jira. Ёмкость рассчитывайте по графику, отсутствиям, доле участия и коэффициенту планирования. Для активного спринта учитывайте оставшуюся часть периода. Если Jira не вернула корректные даты, ёмкость неизвестна.
- Для активного спринта используйте Remaining Estimate незавершённых задач. Для будущего учитывайте статус переноса и правила оценок из README. Различайте неизвестную оценку и явный ноль, соблюдайте выбранное правило учёта подзадач.
- Публикуйте состояние спринта, задачи и время получения вместе после успешного чтения всех страниц. При сбое показывайте последний успешный снимок с признаком устаревания.
- При изменении формата файла команды проверьте совместимость со старыми экспортами. Импорт заменяет состав в черновике после подтверждения. Сохранение настроек применяет замену.

## Проверки

Запускайте из корня проекта на Node.js 22+.

```sh
node --test test/*.test.mjs
node test/chromium.mjs --standalone
```

Первая команда проверяет расчёты, пагинацию и формат файлов команды. Вторая запускает Chromium и проверяет интерфейс с имитацией Jira и API Chrome. Для проверки загружаемого расширения используйте `node test/chromium.mjs` в профиле, который разрешает распакованные расширения.

При выпуске обновляйте версию в `jira-sprint-load/manifest.json` и пересобирайте `jira-sprint-load.zip` из папки расширения. При изменении пользовательского сценария обновляйте README.
