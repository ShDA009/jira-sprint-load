# Загрузка спринта Jira

Расширение Chrome для одной Scrum-доски Jira Cloud или Data Center. Нажмите иконку расширения, чтобы открыть боковую панель с загрузкой команды и списками задач.

```mermaid
flowchart LR
    A["Jira: даты спринта и задачи"] --> C["Боковая панель Chrome"]
    B["Настройки: график, участие и отсутствия"] --> C
    C --> D["Назначено / доступно"]
    C --> E["Осталось работы / доступно"]
```

Скриншоты сделаны на вымышленных задачах и участниках.

## Установка

1. В Chrome 116+ откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение» и выберите папку `jira-sprint-load`.
3. Откройте Jira и нажмите иконку расширения. В настройках проверьте подключение, выберите доску и добавьте участников.

## Как работает

- Расширение берёт даты из Jira и рассчитывает ёмкость по рабочему графику, отсутствиям, доле участия и коэффициенту планирования.
- Будущий спринт использует Original Estimate, а для перенесённых задач — Remaining Estimate, если команда ведёт его и значение есть. Активный спринт использует Remaining Estimate незавершённых задач. Неизвестные оценки и задачи без исполнителя видны отдельно.
- Панель перечитывает данные после сохранений в Jira и при открытой панели опрашивает Jira примерно каждые 15 секунд. При ошибке виден последний успешный результат с отметкой времени.
- Настройки и кеш хранятся локально. Состав команды, графики и отсутствия можно перенести через JSON в разделе «Команда». Импорт применяется после подтверждения и сохранения.

## Проверки

```sh
node --test test/*.test.mjs
node test/chromium.mjs --standalone
```

Для модульных тестов нужен Node.js 22+, для сценариев интерфейса — Chromium. Браузерные проверки используют тестовую Jira. Инструкции по сопровождению собраны в [AGENTS.md](AGENTS.md).
